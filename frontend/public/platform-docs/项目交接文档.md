## 一、项目概述

### 1.1 项目背景

**业务需求：**
- 煤矿上报文档自动化解析
- 关键信息提取（KIE）
- 支持多种清单类型（首期9类瓦斯清单）
- 为下游业务规则判断提供结构化数据

**技术选型依据：**
- 评审了4组方案（cc组、Cd组、D组、hmm组）
- 选定方案D（完美融合方案）
- 融合了各组优势，创新性地提出多路径融合算法

### 1.2 核心目标

| 指标 | Phase 0目标 | 生产目标（Phase 3）|
|------|-------------|-------------------|
| 准确率 | > 90% | 95-98% |
| 处理速度 | < 10秒 | < 2.5秒 |
| GPU占用 | < 0.1个 | < 0.03个 |
| 清单支持 | 1类 | 9类（瓦斯） |
| 日处理量 | 1,000份 | 10,000+份 |

### 1.3 技术亮点

1. **多路径融合提取算法**（核心创新）
   - 规则提取（80%）+ LLM提取（15%）+ 视觉提取（5%）
   - 投票+加权+一致性检查

2. **三级配置体系**
   - Level 1: 自然语言配置（80%场景）
   - Level 2: 配置+模板（15%场景）
   - Level 3: 代码实现（5%场景）

3. **六层质量验证**
   - 页面质量→字段验证→多路径一致性→业务规则→坐标准确性→整体置信度

4. **D组代码复用**
   - 40%直接复用（contracts.py等）
   - 30%改造复用（quality逻辑等）
   - 30%新写（融合算法等）

## 三、关键配置说明

### 3.1 后端配置（必须修改）

**配置文件：** `backend/config/local.yaml`

```yaml
# 数据库配置（必须修改）
database:
  host: "your-postgres-host"          # PostgreSQL地址
  port: 5432
  database: "document_parser"
  username: "your_user"               # 数据库用户名
  password: "your_password"           # 数据库密码

# Redis配置（必须修改）
redis:
  host: "your-redis-host"             # Redis地址
  port: 6379

# MinIO配置（必须修改）
minio:
  endpoint: "your-minio-host:9000"    # MinIO地址
  access_key: "your_access_key"       # MinIO访问密钥
  secret_key: "your_secret_key"       # MinIO密钥
  bucket: "documents"

# 模型服务配置（必须修改）
models:
  ocr:
    base_url: "http://your-ocr-server:port"
    api_key: ""                       # 如不需要认证，留空
  text_llm:
    base_url: "http://your-llm-server:port/v1"
    api_key: ""
    model_name: "qwen3.7-27b"
  vision_llm:
    base_url: "http://your-vision-server:port/v1"
    api_key: ""
    model_name: "qwen3.6-27b"
```

**配置步骤：**
```bash
cd backend
cp config/default.yaml config/local.yaml
notepad config/local.yaml  # 修改上述配置项
```

## 十、常见问题排查

### Q1: 数据库连接失败

```bash
# 检查PostgreSQL是否运行
docker ps | grep postgres

# 测试连接
psql -h your-host -U your_user -d document_parser -c "SELECT 1"
```

### Q2: Redis连接失败

```bash
# 检查Redis是否运行
docker ps | grep redis

# 测试连接
redis-cli -h your-host ping
```

### Q3: MinIO上传失败

- 访问MinIO控制台：http://your-minio-host:9001
- 检查bucket是否存在（名称：`documents`）
- 检查access_key和secret_key

### Q4: 模型服务调用失败

```bash
# 测试OCR服务
curl http://your-ocr-server/health

# 测试LLM服务
curl http://your-llm-server/v1/models
```
