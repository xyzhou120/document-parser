## ⚠️ 风险与应对

### 高风险项

#### 1. 真实文档准确率不达标

**风险等级：** 🔴 高

**应对措施：**
- Phase 0尽早测试真实文档
- 准备多个煤矿的文档样本
- 根据实际结果调整策略
- 必要时降级到方案A（更重规则）

#### 2. GPU资源不足

**风险等级：** 🟡 中

**应对措施：**
- 优先使用规则提取（不占GPU）
- LLM批量调用（减少GPU等待）
- 增加GPU服务器（如需）
- 使用更小的模型（如qwen-7b）

#### 3. 扫描件识别准确率低

**风险等级：** 🟡 中

**应对措施：**
- 多OCR交叉验证
- 图片预处理增强
- 人工复核机制
- 视觉模型兜底

### 中风险项

#### 4. 配置化难度超预期

**风险等级：** 🟢 低

**应对措施：**
- 先支持简单字段
- 复杂字段代码实现
- 逐步增强配置能力

#### 5. 性能不达标

**风险等级：** 🟢 低

**应对措施：**
- 缓存优化
- 数据库查询优化
- 并发处理
- 异步任务优化
