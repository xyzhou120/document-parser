# 快速启动指南

本指南将帮助您在 **10分钟内** 启动智能文档解析平台。

---

## 🚀 快速启动（3步走）

### Step 1: 克隆项目（如果还没有）

```bash
cd D:\西安院\深度监察\文档解析平台\document-parser
```

### Step 2: 配置服务地址

编辑 `backend/config/local.yaml`（从示例复制）：

```bash
cd backend
copy config\default.yaml config\local.yaml
notepad config\local.yaml
```

**必须修改的配置项：**

```yaml
# 数据库（填入您的PostgreSQL地址）
database:
  host: "your-postgres-host"
  username: "your_user"
  password: "your_password"

# Redis（填入您的Redis地址）
redis:
  host: "your-redis-host"

# MinIO（填入您的MinIO地址）
minio:
  endpoint: "your-minio-host:9000"
  access_key: "your_access_key"
  secret_key: "your_secret_key"

# 模型服务（填入您的模型服务地址）
models:
  ocr:
    base_url: "http://your-ocr-server:port"
  text_llm:
    base_url: "http://your-llm-server:port/v1"
  vision_llm:
    base_url: "http://your-vision-server:port/v1"
```

### Step 3: 启动服务

#### 方式A: Docker Compose（推荐，一键启动）

```bash
# 回到项目根目录
cd ..

# 启动所有服务（包含PostgreSQL、Redis、MinIO）
docker-compose -f docker-compose.dev.yml up -d

# 查看日志
docker-compose -f docker-compose.dev.yml logs -f
```

访问：
- 前端：http://localhost:3000
- 后端API：http://localhost:8000/docs

#### 方式B: 本地开发

**终端1 - 启动后端：**

```bash
cd backend

# 安装Poetry（如果还没有）
pip install poetry

# 安装依赖
poetry install

# 初始化数据库
poetry run python -c "from app.storage.database import init_db; import asyncio; asyncio.run(init_db())"

# 启动API服务
poetry run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

**终端2 - 启动Celery Worker：**

```bash
cd backend
poetry run celery -A app.celery_app worker --loglevel=info
```

**终端3 - 启动前端：**

```bash
cd frontend

# 安装pnpm（如果还没有）
npm install -g pnpm

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

访问：http://localhost:3000

## 🛠️ 常见问题

### Q1: 数据库连接失败

**错误信息：** `could not connect to server`

**解决方法：**
1. 检查PostgreSQL是否启动
2. 检查 `config/local.yaml` 中的数据库地址
3. 检查网络连接

### Q2: Redis连接失败

**错误信息：** `Error connecting to Redis`

**解决方法：**
1. 检查Redis是否启动：`redis-cli ping`
2. 检查 `config/local.yaml` 中的Redis地址

### Q3: MinIO上传失败

**错误信息：** `S3 error`

**解决方法：**
1. 访问MinIO控制台：http://your-minio-host:9001
2. 检查bucket是否存在（名称：`documents`）
3. 检查access_key和secret_key是否正确

### Q4: 模型服务调用失败

**错误信息：** `Connection refused` 或 `Timeout`

**解决方法：**
1. 检查模型服务是否启动
2. 测试连接：`curl http://your-model-server/health`
3. 检查 `config/local.yaml` 中的模型服务地址

### Q5: 前端无法访问后端

**错误信息：** `Network Error` 或 `404`

**解决方法：**
1. 检查后端是否启动：http://localhost:8000/docs
2. 检查前端代理配置：`frontend/vite.config.ts`
3. 清除浏览器缓存

### Q6: Celery Worker不工作

**错误信息：** 任务一直是 `PENDING` 状态

**解决方法：**
1. 检查Celery Worker是否启动：`ps aux | grep celery`
2. 检查Redis连接
3. 查看Worker日志：`docker-compose logs -f celery`
